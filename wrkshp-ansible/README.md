# Ansible workshops

The following workshops are intended to learn the Ansible fundamentals:

+ Playbooks.
+ Roles.
+ Facts.
+ Variables, lists and dictionaries.
+ How to iterate through lists and dictionaries.
+ Privilege scalation.
+ Managing secrets, vaults.
