# Containers workshop

This workshop is intended to learn the fundamentals for containers.

You will learn how to build, deploy and manage containers on top of a Linux distribution, Centos Stream 9.

This workshop will introduce you to:

+ [Podman](https://podman.io/).
+ [Buildah](https://buildah.io/).
+ [Skopeo](https://github.com/containers/skopeo).
